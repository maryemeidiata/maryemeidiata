### Projects

| Project | What it does |
|---|---|
| [**Triage**](https://maryemeidiata.vercel.app/projects/triage) | Hospital performance watchlist built on public CMS data. Identifies hospitals that are simultaneously more expensive and producing worse patient outcomes than peer hospitals, state by state. |
| [**We Forgot the Stars**](https://maryemeidiata.vercel.app/projects/we-forgot-the-stars) | Cinematic scrollytelling data essay on light pollution and what we gave away. Thirty years of satellite data, traced city by city, decade by decade. |
| [**Runway**](https://maryemeidiata.vercel.app/projects/runway) | Airline operations analytics tool for identifying routes with a controllable delay problem. Six months of BTS On-Time Performance data, composite risk score, interactive Streamlit dashboard. |
| [**Au-delà**](https://maryemeidiata.vercel.app/projects/au-dela) | Personal sky tracker built on NASA and ESA data. Tells you what is visible tonight from your location, when the ISS passes overhead, and what meteor showers are coming. |
| [**Clarity**](https://maryemeidiata.vercel.app/projects/clarity) | Feed re-ranking engine for Reddit. Describe what you want to see in plain language, it discovers relevant subreddits, fetches posts concurrently, scores them with Cohere on relevance and toxicity, runs VADER sentiment locally, and re-ranks. |
| [**LockIn**](https://maryemeidiata.vercel.app/projects/lockin) | Social accountability app built around real friendships and real stakes. Small groups set weekly commitments, vote on each other's excuses, and get matched by an AI that reads their calendar. In progress. |
| [**Cadence**](https://maryemeidiata.vercel.app/projects/cadence) | Workload intelligence tool that scores tasks by failure probability using a sigmoid model. Builds an EDF or value-density schedule depending on mode. AI strategy coach via Cohere tool use, smart task import via two-pass LLM chain. |
