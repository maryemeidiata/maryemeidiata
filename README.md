### Projects

| Project | What it does |
|---|---|
| [**Clarity**](https://maryemeidiata.vercel.app/projects/clarity) | Feed re-ranking engine for Reddit. Describe what you want to see in plain language, it discovers relevant subreddits, fetches posts concurrently, scores them with Cohere on relevance and toxicity, runs VADER sentiment locally, and re-ranks. Includes a transparency panel so you can see exactly why each post ranked where it did. |
| [**Cadence**](https://maryemeidiata.vercel.app/projects/cadence) | Workload intelligence tool that scores tasks by failure probability using a sigmoid model combining urgency, overload severity, competition pressure, and dependency risk. Builds an EDF or value-density schedule depending on mode. AI strategy coach via Cohere tool use, smart task import via two-pass LLM chain, PDF and ICS exports. |
| [**Au-delà**](https://maryemeidiata.vercel.app/projects/au-dela) | Personal sky tracker built on NASA and ESA data. Tells you what is visible tonight from your location, when the ISS passes overhead, and what meteor showers are coming. |
| [**We Forgot the Stars**](https://maryemeidiata.vercel.app/projects/we-forgot-the-stars) | Scrollytelling data essay on light pollution across European cities. Thirty years of satellite data, mapped and measured. In progress. |
| [**Talk to your finances**](https://maryemeidiata.vercel.app/projects/talk-to-your-finances) | Conversational interface for personal finance. Replaces banking app menus with plain-language queries. In progress. |
| [**Luxury location intelligence**](https://maryemeidiata.vercel.app/projects/luxury-location-intelligence) | Location scoring model for luxury brand flagship decisions in Europe. Built on tourism flows, wealth distribution, brand density, and real estate data. In progress. |
